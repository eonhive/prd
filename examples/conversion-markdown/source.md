# PRD Convert Example

This report was reconstructed from Markdown into responsive PRD content.

## Reading order

- Headings retain their levels.
- Lists and quotes remain structured.
- Local images travel with the document.

> The source and conversion report are declared package attachments.

## Reported limitations

Inline **emphasis** becomes plain text. The original syntax stays in the source attachment.
