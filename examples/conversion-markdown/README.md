# Markdown conversion example

`source.md` and `flow.png` are real input fixtures. `converted.prd` is generated by the repository CLI; `quality.json` is the report extracted from that archive. It is unsigned and uses the default ZIP transport.

From the repository root after installing workspace dependencies:

```sh
pnpm --filter @eonhive/prd-cli build
node packages/prd-cli/dist/cli.js convert examples/conversion-markdown/source.md --out examples/dist/converted-markdown.prd --json
node packages/prd-cli/dist/cli.js validate examples/dist/converted-markdown.prd --json
```

The output parent directory must exist and the destination must be new. Open `converted.prd` with the existing web Viewer's **Open .prd** action. Info reports `fully-supported`; Files lists the raster image, source and conversion-quality attachments. The code block remains in the source attachment, and its omission from the reading view is reported. See the [architecture record](../../docs/architecture/PRD_CONVERT_PHASE_1.md).
