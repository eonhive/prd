# Browser conversion example

`converted.prd` and `quality.json` were downloaded from the production-built PRD Convert page during local browser acceptance on October 28, 2026. They are actual Web Worker conversion output. The source and selected image are the existing [Markdown source](../conversion-markdown/source.md) and [flow image](../conversion-markdown/flow.png).

The result contains eight canonical content nodes, one unchanged 480×144 PNG, exact source bytes and a declared quality report. Its two warnings are the shared Markdown subset limitation and skipped fenced code. The logical output matches Node conversion; ZIP timestamps may differ.

To repeat:

```sh
pnpm viewer:demo:build
pnpm --filter @eonhive/prd-web-viewer exec vite preview --host 127.0.0.1
```

Open the printed local URL at `/convert/`, select the linked source and image using the two file controls, and choose **Convert to PRD**. Review warnings, download the PRD/report and choose **Preview in Viewer**. With a configured hosting base, use `<base>/convert/`.

Local acceptance verified the real worker, valid/fully-supported Viewer opening, decoded image, retained result on return, unsupported-source rejection/recovery, missing-image warnings and explicit source opt-out. Internal screenshots and opt-out output are ignored under `examples/dist/convert-web-qa/`. No deployment or publication was performed.

See [execution boundary and limits](../../docs/architecture/PRD_CONVERT_WEB.md). The initial example above covers Markdown. Browser HTML and CBZ are implemented in the continuations below; additional formats still use the Node CLI.
